# قاعدة البيانات

| المجلد | فيه إيه |
|---|---|
| [`schema/`](schema/README.md) | **مصدر الحقيقة.** ملفات مرقّمة (01، 02، …) بتبني القاعدة كاملة بالترتيب. أي تعديل = ملف جديد بالرقم اللي بعده |
| `tools/` | استعلامات **قراءة بس** للفحص — آمنة في أي وقت |

- الملفات بتتشغّل في Supabase ← SQL Editor، **بعد** ما الكود يتنشر.
- مفيش تعديل يدوي من لوحة Supabase — أي تغيير مالوش ملف هنا بيضيع لو القاعدة اتبنت تاني.
- بعد أي ملف جديد، `src/types/supabase.ts` بيتحدّث في نفس الدفعة.
