## مصدر الحقيقة هو القاعدة نفسها

المجلد ده **ما بيوصفش شكل قاعدة البيانات**. التعديلات بتتشغّل من محرر
SQL في Supabase مباشرة، ومفيش ملف هنا بيضمن إنه مطابق للإنتاج.

عشان تعرف الوضع الحقيقي لجدول أو سياسة حماية، اقرا القاعدة باستعلام —
ملفات `sql/38-*` معمولة للغرض ده بالظبط، وكلها قراءة فقط.

## ليه اتشال مجلد `migrations`

كان فيه 10 ملفات من أول إنشاء للقاعدة، والقاعدة اتغيّرت بعدها بعشرات
التعديلات. الملفات دي بقت **مضلِّلة**: مراجعة أمان اتعملت في
2026-09 اتكتب فيها أربع ملاحظات «حرجة» مصدرها الملفات دي، وتلاتة منهم
كانوا متصلّحين فعلًا في القاعدة من زمان. واحدة بس طلعت حقيقية.

الملفات لسه موجودة في تاريخ git لو احتاجها حد:

```bash
git log --diff-filter=D --name-only -- supabase/migrations
git show <hash>^:supabase/migrations/05_create_instructors_and_bookings.sql
```

## الخطوة الصح اللي لسه ما اتعملتش

تركيب أداة Supabase الرسمية وسحب شكل القاعدة الحقيقي:

```bash
supabase link --project-ref <معرّف-المشروع>
supabase db pull
```

ده بيولّد ملف ترحيل **مطابق للإنتاج**، وبيفضل مطابق مع كل تغيير جاي.
محتاج تثبيت الأداة وكلمة مرور القاعدة. لحد ما يتعمل، الطريقة الوحيدة
لمعرفة شكل القاعدة هي قراءتها باستعلام.
